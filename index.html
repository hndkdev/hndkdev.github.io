About Me

Saya merupakan lulusan Teknik Informatika dari Universitas Cendekia Abditama yang telah menyelesaikan seluruh persyaratan akademik. Saya memiliki minat pada pengembangan perangkat lunak dan aplikasi berbasis web, dengan pengalaman mengembangkan beberapa proyek, seperti aplikasi web, REST API, penerapan Natural Language Processing (NLP), dan game edukasi.
Saya terbiasa menggunakan Python, PHP, JavaScript, HTML, dan CSS, serta berbagai framework dan tools sesuai kebutuhan proyek. Melalui proyek akademik, kegiatan pengabdian masyarakat, dan pengembangan mandiri, saya terus mengembangkan keterampilan dalam membangun aplikasi dan menerapkan solusi teknologi. Saat ini, saya terbuka terhadap kesempatan untuk memulai karier di bidang software dan web development, khususnya pada posisi junior developer.
